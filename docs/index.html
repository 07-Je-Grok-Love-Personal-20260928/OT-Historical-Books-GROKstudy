💎 为什么要读历史书？

📜

它是真实的历史

救恩不是神话，而是神在时间与空间中的作为。历史书提供了从摩西到玛拉基的历史骨架。

🗣️

它是先知的书

希伯来圣经把约书亚记到列王纪称为“前先知书”：这是先知式的历史解释，用神的约来评价历史。

🪞

它是为我们写的

“他们遭遇这些事都要作为鉴戒，并且写在经上，正是警戒我们这末世的人”（林前10:11）。

✝️

它指向基督

“这经就是为我作见证的”（约5:39）。地、王、殿、归回——都是基督的影子。

⭐ 重点

阅读原则（改革宗）：① 唯独圣经（BC 7）——经文本身是最高权威；② 以经解经——历代志与列王纪互相参照；③ 救赎历史——每段历史在神的救恩计划中的位置；④ 基督中心——但不随意寓意化，先明白原意，再沿着圣约的线索走向基督。
